# Webring 画面（`web/webring.js`, `web/graph.js`）

[`../views.md`](../views.md) の子ページ。使う API は [`/api/webring`](../http-api/nostr.md#get-apiwebringrootkeydepthn) と [`/api/replicas`](../http-api/nostr.md#get-apireplicaskeykey)。

## 画面

- root/depth のクエリ（depth は 0〜4 に丸める）は `swing:webring:query` に保存し、次に開いたときに復元する。
- `document` に `swing:show-self-in-webring`（`notify-settings.js::SHOW_SELF_IN_WEBRING`）を投げると、Webring 画面に移って自分（`cache.overview.pubkey`）のノードを選んだ状態にする。今のクエリのグラフを読み込み（キャッシュがあればそれ）、自分のノードがあればそれを選ぶ。無ければ root を空（＝自分）にしてクエリを保存し直し、読み込み直してから選ぶ（depth は変えない）。ブラウザの通知のクリックが使う（[`../notices.md#おしらせの出し分け`](../notices.md#おしらせの出し分け)）。
- 再取得中は既存の表示を消さず `aria-busy="true"` で薄く表示する。表示中の内容が無いときだけ「Loading webring…」になる。
- ノードの名前は `label` に、`more_sites` が 0 より大きければ ` +N` を添えたもの（[`../../webring.md#ノードの名前`](../../webring.md#ノードの名前)）。グラフ・`list` 表示・詳細パネルの見出しで使う。詳細パネルの名前の一覧には `names` のすべてを出す。
- 絵文字のフィンガープリント（[`../fingerprint.md`](../fingerprint.md)）: `list` 表示のアカウントの行・Mutual と One-way の行（両端それぞれ）・`referencing` の行と、詳細パネルの見出し（名前の上の行）・報告者一覧に 4 つ出す。グラフではノードの円の中に先頭の 1 つを出す（[下記](#グラフwebgraphjs)）。
- ノードの選択で `/api/replicas?key=` を引き、詳細パネルを出す。報告者一覧は npub の後ろに最新版か古い版かのタグと tier のタグ（`author` は `[author]`、`chosen` は `[chosen]`、それ以外は `[unverified]`。日本語表示では `[作者]`・`[フォロー中]`・`[未検証]`）を付け、`site.dropped` が 0 より大きければ末尾に「…and N more」相当のヒント文を出す（[`../../nostr/fetch.md`](../../nostr/fetch.md)）。レプリカ数のバッジは `unverified` が 0 より大きければ未検証の件数も添える。
- 詳細パネルには「ルートにする」ボタン（root をそのノードに替えて depth はそのままで読み込み直す）と、ミラー操作を置く。ミラー操作は、選んだノードが自分自身ならボタン無し、ミラー済みなら削除ボタン、未ミラーなら追加ボタン。判定はキャッシュ済みの `/api/sites` か `/api/mirror` の pubkey 集合（どちらも無ければ `/api/mirror` を読む）。
- `beyond` と `over_budget`（意味は [`../../webring.md`](../../webring.md#グラフwebringbuild_graph)）は、0 より大きければ画面下部にヒント文を 1 行ずつ出す。`list` 表示では `referencing`（起点を名指ししているだけでクロールには加えていないアカウント）を「Mutual」「One-way」と並ぶグループとして出し、`more` が 0 より大きければ末尾に件数のヒント文を添える（[`../../webring.md`](../../webring.md#たどり方webringcrawl)）。

## グラフ（`web/graph.js`）

外部ライブラリを使わない force-directed layout。ドラッグでノードを固定でき、クリックで選択して詳細パネルを開く。キーボード操作（Tab で移動、Enter/Space で選択）に対応する。パン・ホイールズーム（0.15〜4 倍）と全体表示（Fit。倍率は 0.15〜3 倍）ができる。`prefers-reduced-motion: reduce` ではアニメーションせず、止まるまで（最大 5000 ステップ）同期で進めてから 1 回だけ描画する。ノード・辺は class と `data-*` だけを持ち、色は CSS 側で当てる（[`../css.md`](../css.md)）。各ノードの円（半径 10）の中央にフィンガープリントの先頭の絵文字を 14px の `<use class="swing-node-emoji">` で重ねる。`aria-hidden` でポインタのイベントも受けないので、選択・ドラッグ・フォーカスはノードの `<g>` が受ける。ラベル（16 文字で切り詰める）・`<title>`・`aria-label` には ` +N` を切り詰めずに添える。

- 初期位置: 深さごとの同心円に置く。深さ 0 が 1 つなら中心、それ以外の輪は前の輪から `LINK_DISTANCE`（90）外側で、ノードが多ければ 1 つあたり 60（`RING_SPACING`）の円周が取れる半径まで広げる。各ノードの角度は、内側の輪で置き済みの隣接ノードの角度の円平均を目標にし、目標の順に等間隔に並べる（無ければ並び順で等間隔）。乱数は使わない。
- 力: 全ノード対の反発（`REPULSION / 距離²`）、辺のばね（目標の長さ `LINK_DISTANCE`）、中心への弱い引力に加え、ラベルを含めた矩形（円とラベルの幅、高さ 14、余白 6。ラベルの幅と高さは画面上の大きさを今の倍率で割ったグラフ上の大きさ）が重なる対を重なりの小さい軸の向きに押し離す。ノードが 150 以下なら、両端でない辺から 22 未満のノードを辺から押し離す（辺の両端は逆向きに半分ずつ）。`alpha` は 1 から毎ステップ 0.004 ずつ下げ、0.01 以下か最大速度が 0.03 以下で止める。
- ラベルの向き: 毎ステップ、ノードの左右それぞれについて、出ている辺がラベルの帯（高さ 14）と重なる長さ（ラベルの幅まで。どちらもグラフ上の大きさ）を足し、少ない側に出す（同じなら右）。ラベルは円の端から 2（枠の太さの分）と画面上の 4px 離し、左に出すときは `text-anchor="end"` にする。ラベルは背景色（`--swing-surface`）の縁取り（`paint-order: stroke`、画面上で 3px）を持つ。ラベルの幅は描画後に `getComputedTextLength()` で測り、測れなければ 1 文字 6.6px とみなす。
- 表示まで: 描画の前に最大 150ms 同期でステップを進める。止まったら全体表示し、その倍率で測り直したラベルの大きさが 5% より変わるときは、`alpha` を 0.3 まで戻して同じ時間の残りで進め直し、全体表示し直す（最大 3 回）。ドラッグで動かし直すときは、そのときの倍率でラベルの大きさを測る。時間内に止まらなければ、続きをアニメーションで進めて止まったところで全体表示する（パン・ズームした後は全体表示しない）。全体表示の左右の余白は、その側に出ているラベルの最大幅から決める（画面幅の 30% まで）。
