# マスコットのパック（`src/dashboard/mascots/`, `web/desktop-mascot-pack.js`）

[`../mascot.md`](../mascot.md) の子ページ。パックをサーバが読み込んで配信する規則と、パックの形式（マニフェストのキー・値の範囲・検証）。パックを作る人向けの手順は [`../../../mascot-guide.md`](../../../mascot-guide.md)。

## 配信（`src/dashboard/mascots/`）

| パス | 内容 |
|---|---|
| `GET /mascots/index.json` | `{"packs": [{"id": "yureko", "base": "/mascots/yureko/"}, ...]}`。同梱パック（`yureko`・`mochi`・`neko`）→ ユーザー定義パック（id 昇順）の順で、この順が表示順（[`../mascot.md#層フォーカス幅`](../mascot.md#層フォーカス幅)） |
| `GET /mascots/<id>/manifest.json` | パックのマニフェスト（中身に手を加えずに返す） |
| `GET /mascots/<id>/<sprite>` | スプライトシート。`<sprite>` はマニフェストの `sprite` そのもの |

- どれもログインが要る（[`security.md#ガード`](../security.md#ガード)）。ほかの `{id}`・`{file}` の組み合わせは `404`。
- `ui = true` のときだけ、`AppState::new` が `mascots::MascotRegistry::load` で起動時に 1 回読み、マニフェスト・スプライトのバイト列と `index.json` の本文をメモリに持つ（反映の条件は [`../../dashboard.md#設定dashboard`](../../dashboard.md#設定dashboard)）。
- 同梱パック（`web/mascots/<id>/`）はバイナリに埋め込んであり、常に読み込める。
- `mascots/mod.rs` が読み込みと配信、`mascots/nofollow.rs` がリンクを辿らない open と上限付きの読み込み（`read_limited`）、`mascots/image.rs` がスプライトのヘッダの検証（`check_sprite`）を持つ。

### `mascots_dir` の読み込み

読み飛ばすものは `warn!` でエントリ名（`Debug` 形式）と理由を出し、`swing up` は止めない（`mascots_dir` 自体が無い・読めないときも同梱パックだけで続ける）。個別の `warn!` は 1 回の読み込みで 10 件までで、残りは件数を 1 行にまとめる。

1. **候補を集める**: 直下のエントリを最大 1024 個まで見る（超えた分は 1 行の `warn!` を出して見ない）。ファイルは開かず、名前とエントリの種類（リンクを辿らない）だけで判定する。名前（= パック id）が UTF-8 で `^[a-z0-9][a-z0-9-]{0,31}$` に一致し、同梱の id と重ならず、シンボリックリンクでないディレクトリが候補。
2. **上限で切る**: 候補を id の昇順に並べて先頭の 32 個だけを残す。後の検証で落ちるものがあっても、33 個目以降は繰り上がらない。
3. **各パックを読む**: 次をすべて満たさなければ読み飛ばす。
   - パックディレクトリ・`manifest.json`・スプライトを、リンクを辿らずに開き、開いたハンドルのメタデータで判定する。Unix では `mascots_dir` を開いたディレクトリを基準に `openat(O_NOFOLLOW | O_NONBLOCK)` でパックディレクトリ（`O_DIRECTORY` 付き）を、さらにそれを基準にファイルを開く（FIFO は待たずに、通常ファイルでないとして落ちる）。Windows では `FILE_FLAG_OPEN_REPARSE_POINT` で開いてリパースポイントなら落とし、ハンドルの実パス（`GetFinalPathNameByHandleW`）の親が、`canonicalize` した `mascots_dir`（パックディレクトリのとき）かパックディレクトリの実パス（ファイルのとき）と一致することを確かめる。
   - `manifest.json` とスプライトが通常ファイルで、Unix ではハードリンクの数が 1。
   - `manifest.json` が 64 KiB 以下で JSON オブジェクトとしてパースでき、`format` が `1`、`sprite` がプレーンなファイル名（`/`・`\`・`..` を含まず `.` で始まらない。拡張子が大文字小文字を問わず `.png`・`.gif`・`.webp`）。それ以外の検証はフロントエンド（下記「[パック形式 1](#パック形式-1)」の「検証」）に任せる。
   - スプライトが 1 MiB 以下（読むときも上限 + 1 バイトまでしか読まない）。
   - スプライトのヘッダ（PNG の `IHDR`、GIF の論理画面記述子、WebP の `VP8 `・`VP8L`・`VP8X` チャンク）から得た形式が拡張子と一致し、幅・高さが 1 px 以上で、「[パック形式 1](#パック形式-1)」のシートの上限以内。

### フロントエンドの読み方

`index.json` と各エントリの `base` だけを頼りに読む。`base` は同一オリジンでなければならず、`manifest.json` は `base` の直下に置き、`sprite` は `base` の下に解決できるものに限る。

## パック形式 1

パックは `manifest.json` とスプライトシート 1 枚（PNG・GIF・WebP。幅・高さはどちらも 4096 px 以下、幅 × 高さは 4,194,304（2048 × 2048）ピクセル以下）からなるディレクトリ。シートは同じ大きさのコマを格子状に並べ、左上から右へ、行が尽きたら次の行へ 0 から番号を振る（列数・行数は画像の大きさをコマの大きさで割って切り捨てたもの）。

```json
{
  "format": 1,
  "name": "表示名",
  "sprite": "sprite.png",
  "frame": { "width": 48, "height": 48 },
  "scale": 1,
  "anchor": { "x": 24, "y": 48 },
  "balloon": { "x": 24, "y": 6 },
  "facing": "right",
  "speed": 24,
  "animations": {
    "idle": { "frames": [0, 1], "fps": 2 },
    "walk": { "frames": [{ "index": 2, "ms": 120, "dx": 2 }, { "index": 3, "ms": 120, "dx": 2 }] },
    "surprise": { "frames": [10], "fps": 1, "loop": false }
  },
  "overlays": {
    "blink": { "frames": [12, 13], "fps": 8, "interval": [2500, 6000], "on": ["idle", "walk", "talk"] },
    "mouth": { "frames": [14, 15], "fps": 6, "on": ["talk"] }
  },
  "lines": {
    "greet": ["やっほー！"],
    "site-stored": ["{title} が更新されたよ！"]
  }
}
```

| キー | 必須 | 内容 |
|---|---|---|
| `format` | ○ | `1` |
| `name` | | 表示名（40 文字を超える分は切り詰める） |
| `sprite` | ○ | シートのファイル名（`base` からの相対） |
| `frame.width` `frame.height` | ○ | 1 コマの大きさ（整数 8〜128、シート上の px） |
| `scale` | | 表示倍率（整数 1〜4、既定 1）。画面上の大きさは `frame × scale` CSS px |
| `anchor` | | 足元の点。ピクセルの境目の座標（整数、`0 ≤ x ≤ width`・`0 ≤ y ≤ height`。`y = height` はコマの下端、`x = 24` は 23 列目と 24 列目の境目）。既定は `{x: floor(width / 2), y: height}`。この点を地面（タスクバーの上端）に合わせ、ドラッグ中もこの点を基準に動かす |
| `balloon` | | 吹き出しの尾が指す点（ふつうは頭のすぐ上）。座標の取り方は `anchor` と同じ（整数、`0 ≤ x ≤ width`・`0 ≤ y ≤ height`）。既定はコマの上端の中央（`{x: width / 2, y: 0}`）。使い方は [`../mascot.md#吹き出しの位置`](../mascot.md#吹き出しの位置) |
| `facing` | | シートの絵が向いている向き（`right` / `left`、既定 `right`）。逆向きは水平反転で描く（反転しても `anchor`・`balloon` が同じ部位に来るよう、`x` を `width - x` に写す）。`flip: false` のアニメーションの間は反転しない |
| `speed` | | 歩く速さ（シート上の px / 秒、0 より大きく 1000 以下、既定 24）。`walk` のコマに 0 以外の `dx` が 1 つも無いときだけ使う |
| `animations` | ○ | 名前 → アニメーション。`idle` は必須 |
| `overlays` | | 重ね絵（`blink`・`mouth`） |
| `lines` | | せりふ |

**アニメーション**: 名前は `idle`（待機）・`walk`（歩く）・`talk`（吹き出しを出している間）・`sleep`（寝る）・`surprise`（おしらせが来たとき）・`drag`（つままれている間）・`fall`（落ちている間）。`idle` 以外は省略でき、無いものは `idle` で代用する。各アニメーションは `{frames, fps?, loop?, flip?}`:

- `frames`: 空でない配列（最大 256 要素）。要素はコマ番号（整数、表示時間は `1000 / fps` ms）か `{index, ms?, dx?, dy?}`。`ms` は表示時間（省略時 `1000 / fps`）。どちらの書き方でも、各コマの表示時間は 16〜60000 ms でなければならない。`dx` はそのコマに入ったときに進む横方向の距離（シート上の px、`-frame.width`〜`frame.width`）で、`walk` でだけ使う。符号は無視し、常に目標の方向へ進む。`walk` のどれかのコマに 0 以外の `dx` があれば、歩く距離は `speed` ではなく `dx` で決まる。`dy` はそのコマを描く縦のずれ（シート上の px、下が正、`-frame.height`〜`frame.height`）で、位置は変えない（跳ねる絵などに使う）。吹き出しの点と当たり判定は `dy` ぶん絵と一緒にずれる。
- `fps`: 0 より大きく 60 以下の数、既定 4（表示時間の範囲から、実際に使えるのは 1/60 以上）。
- `loop`: 真偽値（それ以外は検証で落ちる）。既定 `true`。`false` なら最後のコマで止まる。
- `flip`: 既定 `true`。`false` なら逆向きのときも水平反転せずシートの向きのまま描く（同梱の `mochi`・`neko` が `sleep` に使う）。ふるまいは [`../mascot.md#ふるまい`](../mascot.md#ふるまい)。

**重ね絵**: 同じシートの同じ大きさのコマを、土台のコマのちょうど上（`dy` も同じ）に重ねる。`frames`・`fps` はアニメーションと同じ書き方。`loop` は使わない（真偽値でなければアニメーションと同じく検証で落ちる）。

- `blink`: 今のアニメーションが `on`（既定 `["idle", "walk", "talk"]`）に含まれる間、`interval`（`[最小, 最大]` ms、どちらも 100〜600000 で最小 ≤ 最大、既定 `[2500, 6000]`）のあいだの乱数の間隔で 1 回ずつ再生する。
- `mouth`: 今のアニメーションが `on`（既定 `["talk"]`）に含まれ、かつ吹き出しの文字送りが終わるまでの間、繰り返す。

**せりふ**: 種類 → 文字列か文字列の配列（出すたびに 1 つを無作為に選ぶ。200 文字を超える分は切り詰め、文字列でない要素は捨てる）。無い種類は組み込みの日本語の既定文を使う。

| 種類 | 出すとき | 差し込み |
|---|---|---|
| `greet` | Desktop 画面を初めて表示したとき（1 回だけ。「ひとりごとを言う」を外していれば出さない） | |
| `site-stored` | ミラーしたサイトの保存のおしらせが 1 件 | `{title}`（`title` をサニタイズして最大 60 文字、無ければ `d`）、`{d}`、`{count}` |
| `sites-stored-many` | 同じく 2 件以上 | `{count}` |
| `site-published` | 自分のサイトの公開のおしらせが 1 件 | `{title}`（`title` をサニタイズして最大 60 文字、無ければ `d`）、`{d}`、`{count}` |
| `sites-published-many` | 同じく 2 件以上 | `{count}` |
| `replica-added` | 自分のサイトをミラーする人が増えたおしらせが 1 サイト | `{title}`（同上）、`{d}`、`{count}` |
| `replicas-added-many` | 同じく 2 サイト以上 | `{count}`（サイトの数） |
| `fetch-error` | 更新の確認に失敗したとき | |
| `recovered` | 失敗の後に確認できたとき | |
| `idle` | ときどき（数分に 1 回まで。「ひとりごとを言う」を外していれば出さない） | |
| `click` | マスコットをクリックしたとき | |

**検証**: 知らないキーは無視する。次のどれかに当たるパックは `console.warn` を出して丸ごと読み飛ばし、ページは壊さない: `format` が `1` でない、`idle` が無い、上の型・範囲に合わない値がある（`anchor`・`balloon`、既知のアニメーション・重ね絵の中身を含む）、`sprite` が `base` の外を指す、マニフェストかシートを読み込めない、シートを読み込んだ後に使っているコマ番号がシートのコマ数を超える、シートの幅・高さ（`naturalWidth`・`naturalHeight`）が上の上限を超える、シートの画素を読み出せない（[`../mascot.md#当たり判定`](../mascot.md#当たり判定) のマスクを作れない）。
