# Desktop 画面のマスコット（`web/desktop-mascot*`）

[`desktop.md`](desktop.md) の子ページ。Desktop 画面全体（モジュールの一覧）は [`desktop.md`](desktop.md)、コントロール パネルの殻は [`desktop/control-panel.md`](desktop/control-panel.md)、更新の確認とおしらせの出し分けは [`notices.md`](notices.md)。子ページは [`mascot/pack.md`](mascot/pack.md)（パックの配信と形式）。

## 概要

デスクトップの上を歩き回るキャラクター。見た目・動き・せりふはパック（[`mascot/pack.md#パック形式-1`](mascot/pack.md#パック形式-1)）に宣言的に書き、パックに JS は入れられない。同梱のパックは `yureko`・`mochi`・`neko` の 3 つ。加えて、サーバ側で `[dashboard].mascots_dir` を指していれば、その下のサブディレクトリをユーザー定義パックとして読み込む（[`mascot/pack.md#配信`](mascot/pack.md#配信srcdashboardmascots)）。読み込めたパックのうち「コントロール パネル」の「マスコット」タブで選んだもの（既定は `yureko` だけ）を 1 体ずつ出す。

モジュールの分担:

| ファイル | 役割 |
|---|---|
| `desktop-mascot-pack.js` | パックの読み込み・マニフェストの検証と正規化（`normalizeManifest`）・当たり判定用の不透明マスク（`opaqueAt`） |
| `desktop-mascot-sprite.js` | 1 体の描画・コマ送り（`createPlayer`）・配置・当たり判定（`hits`）・吹き出しを向ける点の計算（`box`） |
| `desktop-mascot-behavior.js` | 1 体のふるまいの状態機械 |
| `desktop-mascot-balloon.js` | 吹き出しの中身・文字送り・配置 |
| `desktop-mascot.js` | 全体の進行（`DesktopMascots`）。ループ・おしらせの振り分けと預かり・ポインタ操作と当たり判定の切り替え。吹き出しでおしらせを出せる状態か（`showing()`）をブラウザの通知に教える |
| `desktop-mascot-settings.js` | 「マスコット」タブ |
| `desktop-mascot.css` | マスコットと吹き出しの見た目 |

## ふるまい

1 体ごとの状態機械（`desktop-mascot-behavior.js`）で動く。地面は `#desk-screen` の下端（＝タスクバーの上端）で、横位置は絵がスクリーンからはみ出さない範囲に収める。スクリーンの大きさが変わるたびに（`ResizeObserver`）地面と範囲を取り直す。

- **待機 ⇄ 歩く**: 待機が数秒続くたびに、半分ほどの確率で地面の上の無作為な位置へ歩く（「歩きまわる」を外していれば歩かず、歩いている途中なら止まる）。
- **寝る**: 操作もおしらせも無いまま 1〜2 分たつと寝て、しばらくすると起きる。クリック・ドラッグ・吹き出しでも起きる。
- **反転しないアニメーション**: 今のアニメーションが `flip: false` の間は、向きをシートの `facing` にする（`walk` でも進む向きに関わらず）。描画・吹き出しの点・当たり判定はこの向きで決まる。終わっても元の向きには戻さず、次に歩くときに進む向きへ向き直る。
- **驚く**: おしらせが来ると `surprise` を 1 秒ほど再生する（おしらせを受け持たない他の体も驚く）。
- **話す**: 吹き出しを出している間は歩かず `talk` を再生する。
- **ドラッグ**: 絵の不透明な画素（下記「[当たり判定](#当たり判定)」）を押して 3px 以上動かすとつまみ上げ（`drag`）、離すと重力で地面まで落ちる（`fall`）。ポインタ座標は `toDeskPx` で `#desk-mascots` 内の座標に換算する。動かさずに離せばクリック扱い。
- コマ送りと移動は全体で 1 本の `requestAnimationFrame` ループが進め、Desktop 画面が表示されていてタブが前面にある間だけ回す。間が空いたときのコマ送り（`createPlayer` の `advance`）は、1 周以上の分をまとめて飛ばし（その間の `dx` も足す）、1 回で進めるコマはコマ数 + 1 まで。

## 当たり判定

マスコットは、コマの枠（`frame × scale` の矩形）の中で、いま描いている絵の不透明な画素だけがポインタを受ける。透明な画素のところを押すと、下にあるもの（デスクトップ・アイコン・リンク集ページのリンクなど）にそのまま届く。吹き出しは枠全体（矩形）で受ける。

- **マスク**: パックのシートを読み込んだ後に 1 回だけ canvas に描いて `getImageData` で画素を読み、アルファ値が 128 以上（0〜255 のうち半分以上不透明）の画素を 1 ビットで持つ。
- **当たる画素**: 土台のコマと、いま見えている重ね絵（`blink`・`mouth`）のコマのどれかで、その点の画素が不透明なら当たる。点は `scale` で割ってシートの画素に写し、左右反転中は列を `width - 1 - 列` に写し、各レイヤーの `dy` ぶん上下にずらして引く（`dy` でずれた絵のうち、枠の外にはみ出た部分は当たらない）。
- **切り替えの仕組み**: `.desk-mascot` は既定で `pointer-events: none` で、ポインタが不透明な画素の上にあるマスコット 1 体だけ `is-hot` クラスで受けるようにする。判定はトップの文書とリンク集ページ（iframe）の文書の `pointermove`（タッチ以外）のたびと、ループの各フレームに、最後のポインタ位置でやり直す（iframe の中の座標は `frameToViewport` で換算し、iframe の文書は `DesktopMascots.watchFrame(doc)` で結ぶ）。
- **重なり**: `#desk-mascots` の子を後ろ（手前に描かれるもの）から順に見て、最初に当たった体を取る。途中に点を含む開いた吹き出しがあれば、それより奥の体は当たらない。
- **ドラッグ中**: つまんでいる体は、離すまで `is-hot` のまま（ポインタキャプチャで追う）。離したらその位置で判定し直す。
- **ホバーの無い押下（タッチ・ペンなど）**: トップの文書と iframe の文書の主ボタンの押下をキャプチャ段階で見て、押した点がマスコットの不透明な画素に当たっていれば、下の要素には届けずにその体のドラッグ/クリックを始める（続く `click` とタッチのスクロールも下へは届けない）。モーダルが開いているときと、トップの文書で `#desk-screen` の外か `#desk-mascots` の中（マスコット自身が受ける）を押したときは横取りしない。

## 吹き出し

Win95 のツールチップ風（`#ffffe1`・1px の黒枠・PixelMplus12）で、マスコットを指す小さな尾（高さ 6px）を持つ。文字は 1 字ずつ送る（先に全文ぶんの大きさを取っておくので、送っている間に大きさは変わらない）。マスコットをドラッグすると付いて動く。文字はすべて `textContent` で入れ、改行（種類の違うおしらせのせりふの区切り）はそのまま改行として出す（`white-space: pre-line`）。

### 吹き出しの位置

- **点**: パックの `balloon`（左右反転中は [`facing`](mascot/pack.md#パック形式-1) のとおり写す）に、いま描いている土台のコマの `dy` を足し、`scale` 倍して枠の左上からの位置にしたもの。跳ねる絵でも尾が頭に付いて動く。
- **上に置く**: 吹き出しの下端を点の 6px 上に置き、尾の先を点の 1px 上に合わせる。左右は点を中心にし、スクリーンの内側（端から 4px）に収める。尾は点の真上に置き、吹き出しの左右の端から 4px より外には出さない。
- **下に置く**: 上に置くと吹き出しの上端がスクリーンの上端から 4px 未満になるときは、マスコットの枠の下端の 6px 下に置き（地面より下にはみ出すなら上へ詰める）、尾を上下反転する。尾の左右の位置は上に置くときと同じ（点の真下）。下に置くときの基準は `balloon` ではなく枠の下端。

### おしらせ

- **種類**: `desktopUpdates`（[`notices.md#更新の確認`](notices.md#更新の確認)）の `sites-stored`（ミラーしたサイトの保存）・`published`（自分のサイトの公開）・`replicas-added`（自分のサイトをミラーする人の増加）を受ける。「通知」タブの「デスクトップでおしらせする内容」で外した種類は受けず、預かりもしない（預かっている間に外した種類は、出すときに除く）。Desktop 画面が表示中でタブが前面にあるときだけ吹き出しで出す（それ以外のときの出し分けは [`notices.md#おしらせの出し分け`](notices.md#おしらせの出し分け)）。Desktop 画面が表示されていない間に来たおしらせは預かっておき、次に表示したとき（タブが前面に戻ったときを含む）に、ブラウザの通知のクリックなどで既読になったものを除いて出す。
- **振り分け**: 1 回ぶんのおしらせを 1 体に渡す。おしらせの吹き出しを開いている体か、つままれている間のおしらせを預かっている体があればその体に渡して合流させ、無ければ表示中の体の間で順番に回す。種類が違うおしらせも同じ吹き出しに合流する。同じおしらせ（`key` が同じもの）は 1 つにまとめ、ミラーする人の増加は同じサイトなら加わった報告者を合わせる。表示をやめた体（狭い幅・コントロール パネルでの選択解除）が持っていたおしらせは、表示中の体のうちおしらせの吹き出しを開いているか預かっている最初の体に、無ければ表示中の先頭の体に引き継ぐ。つままれている間に来たおしらせは離したときに出す。パックの読み込みが終わる前に来たおしらせは、読み込み後に振り分ける。
- **中身**: 吹き出しに入っているおしらせを種類ごと（保存 → 公開 → ミラーする人の増加の順）に分け、種類ごとに 1 件なら 1 件用（`site-stored`・`site-published`・`replica-added`）、2 件以上なら 2 件以上用（`sites-stored-many`・`sites-published-many`・`replicas-added-many`）のせりふを 1 行ずつ並べる。その下に種類をまたいで新しい順に最大 5 件のタイトルのリンクと「ほか N 件」。リンクは `href`（`gateway_url` か `url`）を `target="_blank" rel="noopener noreferrer"` で開く。`href` が無いか `http://`・`https://` で始まらない項目（ミラーする人の増加でサイトのリンク先が分からないときなど）はリンクにせずタイトルを文字だけで出す（判定は `util.js::isHttpUrl`。`maybeLink` と同じ）。「とじる」ボタンで閉じるまで出したまま。
- **既読**: おしらせの吹き出しのリンクを開く（クリック・中クリック）か「とじる」を押すと、その吹き出しに入っているおしらせで `desktopUpdates.acknowledge` を呼ぶ（種類ごとに `at` の最大値まで既読を進める。[`notices.md#更新の確認`](notices.md#更新の確認)）。それ以外の閉じ方（狭い幅に切り替わって体が隠れたときなど）では既読にしない（隠れた体のおしらせは表示中の体に引き継ぐ）。
- **読み上げ**: おしらせのせりふとタイトルを `aria-live="polite"` の領域（`#desk-mascot-live`）に入れる。

### ひとこととクリック

- **ひとこと**（`greet`・`idle`・`click`・`fetch-error`・`recovered`）: 文字を送り終えてから 4 秒で閉じ、既読には関わらない。`fetch-error`・`recovered` は Desktop 画面が表示中でタブが前面にあるときだけ言う（預からない）。吹き出しをクリックしても閉じる。おしらせの吹き出しが開いている体は、ひとことを出さない。
- **クリック**: 体を起こし、出していないおしらせを持っていればそれを出す。無ければ、おしらせの吹き出しを開いていない限り `click` のせりふを言う。

## マスコットタブ

「コントロール パネル」（[`desktop/control-panel.md`](desktop/control-panel.md)）の「マスコット」タブ（`desktop-mascot-settings.js::MascotSettingsPage`）。

- **表示するマスコット**: 読み込めたパック（`/mascots/index.json` の順）をチェックボックスの一覧で出す。各行はパックの表示名（無ければ id）と `idle` の最初のコマの静止画（48×48 の枠に収まる最大の整数倍、枠より大きいコマは等倍のまま上端・左右中央に合わせて枠で切り取る）。行を選ぶ（クリックかチェックボックスへのフォーカス）と、上のモニタの枠の中に同じコマを収まる最大の整数倍で出す。全部外してもよい（マスコットは 1 体も出ず、吹き出しのおしらせも出ない。ブラウザの通知を使っていれば、Desktop 画面を表示していてもそちらで出す）。パックの読み込みが終わるまでは「よみこみちゅう…」、1 つも無ければ「マスコットがありません」と出す。
- **動き**: 「歩きまわる」（外すとその場で待機・話す・寝るだけになる。ドラッグはでき、離せば落ちる）と「ひとりごとを言う」（外すと `greet`・`idle` のせりふを出さない。おしらせ・`click`・`fetch-error`・`recovered` は出す）。どちらも既定でオン。
- **永続化**: `swing:desktop:mascot` キー（`notify-settings.js` で定義）に `{"packs": [id, ...], "interval": 60, "walk": true, "chatter": true}` の形の JSON で保存する。`interval` は「通知」タブの項目（[`notices.md#設定`](notices.md#設定)）で、このタブは `packs`・`walk`・`chatter` だけを書き換える。`packs` が `null` なら読み込めたパックを全部出す。`packs` が無い・壊れた/想定外の値は項目ごとに既定（`["yureko"]`・`true`・`true`）へ落とす。
- **`packs` の決まり**: チェックを付け外しすると、保存する `packs` は「今チェックの付いているパックの id」を一覧の順に並べたものになる。全部にチェックが付いていれば `packs` に `null`（全部表示）を書き、1 つでも外れていればその一覧を書く。一覧を保存した後で `mascots_dir` に足したパックは、チェックを付けるまで出ない。一覧にあって今は読み込めないパックの id（`mascots_dir` から消したものなど）は無視し、次にチェックを付け外しして保存したときに一覧から落ちる。
- **適用**: 保存値はページ読み込み時に 1 回 `localStorage` から読んでメモリに持ち、OK/適用のたびに再読み込みせずその場で当てる（`DesktopMascots.applySettings` がマスコットを足し引きする。外したマスコットのおしらせの引き継ぎ先は上記「[おしらせ](#おしらせ)」の振り分けと同じ）。保存に失敗したらエラーを出し、保存値は変えない。

## 層・フォーカス・幅

- マスコットと吹き出しは `#desk-screen` の中の `#desk-mascots`（`z-index: 10`）に入る。アイコンと SWING Explorer ウィンドウより上、コントロール パネルのオーバーレイ・ダイアログより下。足元はタスクバーの上端に乗る。
- `#desk-mascots` 自体はポインタを受けず、吹き出しと、不透明な画素の上にポインタがあるマスコットだけが受ける（上記「[当たり判定](#当たり判定)」）。マスコットはフォーカスを受けず（`aria-hidden`）、吹き出しのリンクと「とじる」は Desktop 画面の Tab の巡回に入る（`#view-desktop` の実機能コントロールにリンクも数える）。フォーカスのある吹き出しが閉じたら「SWING Explorer」アイコンへ移す。
- 表示するマスコットは、`index.json` の順に、表示の幅（フレームの幅 × `scale`）の合計が `#desk-mascots` の幅の 1/4 に収まるところまで出す（先頭の 1 体は必ず出す）。幅が変わるたびに決め直す。

## 動きを減らす設定

`prefers-reduced-motion: reduce` のときは歩かず落ちず、`idle` の最初のコマを止めて出し、重ね絵も出さない（当たり判定と吹き出しの点もこのコマで決める）。吹き出しは出すが文字送りはしない。ドラッグはでき、離すとその場で地面に戻る。
