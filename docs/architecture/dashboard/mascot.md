# Desktop 画面のマスコット（`web/desktop-mascot*`）

[`desktop.md`](desktop.md) の子ページ。Desktop 画面全体（モジュールの一覧・更新の確認・コントロール パネルの殻）は [`desktop.md`](desktop.md)、パックを配信するサーバ側は [`../dashboard.md#マスコットのパック配信srcdashboardmascotsrs`](../dashboard.md#マスコットのパック配信srcdashboardmascotsrs) を参照。

## 概要

デスクトップの上を歩き回るキャラクター。見た目・動き・せりふはパック（下記「[パック形式 1](#パック形式-1)」）に宣言的に書き、パックに JS は入れられない。同梱のパックは `yureko`（64×64）・`mochi`（48×48）・`neko`（32×32）の 3 つで、`yureko` と `mochi` は `scale: 2`、`neko` は `scale: 1` で描く。加えて、サーバ側で `[dashboard].mascots_dir` を指していれば、その下のサブディレクトリをユーザー定義パックとして読み込む（サーバ側の検証規則は [`../dashboard.md#マスコットのパック配信srcdashboardmascotsrs`](../dashboard.md#マスコットのパック配信srcdashboardmascotsrs)）。読み込めたパックのうち「コントロール パネル」の「マスコット」タブで選んだもの（既定は `yureko` だけ）を 1 体ずつ出す。

モジュールの分担（[`desktop.md#構成`](desktop.md#構成) の表と同じ）:

| ファイル | 役割 |
|---|---|
| `desktop-mascot-pack.js` | パックの読み込み・マニフェストの検証と正規化（`normalizeManifest`）・当たり判定用の不透明マスク（`opaqueAt`） |
| `desktop-mascot-sprite.js` | 1 体の描画・コマ送り（`createPlayer`）・配置・当たり判定（`hits`）・吹き出しを向ける点の計算（`box`） |
| `desktop-mascot-behavior.js` | 1 体のふるまいの状態機械 |
| `desktop-mascot-balloon.js` | 吹き出しの中身・文字送り・配置 |
| `desktop-mascot.js` | 全体の進行（`DesktopMascots`）。ループ・おしらせの振り分け・ポインタ操作と当たり判定の切り替え |
| `desktop-mascot-settings.js` | 「マスコット」タブ |
| `desktop-mascot.css` | マスコットと吹き出しの見た目 |

## 配信

| パス | 内容 |
|---|---|
| `GET /mascots/index.json` | `{"packs": [{"id": "yureko", "base": "/mascots/yureko/"}, ...]}`。並び順が表示順（幅が足りなくて一部だけ出すときは先頭から）で、同梱パック（`yureko`・`mochi`・`neko`）→ ユーザー定義パック（id 昇順）の順に並ぶ |
| `GET /mascots/<id>/manifest.json` | パックのマニフェスト |
| `GET /mascots/<id>/<sprite>` | スプライトシート |

フロントエンドは `index.json` と各エントリの `base` だけを頼りに読む。`base` は同一オリジンでなければならず、`sprite` は `base` の下に解決できるものに限る。`manifest.json` は `base` の直下に置く。サーバはマニフェストを中身に手を加えずに返し、`format`・`sprite` 以外の検証はここ（下記「検証」）に任せる。

## パック形式 1

パックは `manifest.json` とスプライトシート 1 枚（PNG・GIF・WebP。幅・高さはどちらも 4096 px 以下、幅 × 高さは 4,194,304（2048 × 2048）ピクセル以下）からなるディレクトリ。シートは同じ大きさのコマを格子状に並べ、左上から右へ、行が尽きたら次の行へ 0 から番号を振る（列数・行数は画像の大きさをコマの大きさで割って切り捨てたもの）。

```json
{
  "format": 1,
  "name": "表示名",
  "sprite": "sprite.png",
  "frame": { "width": 48, "height": 48 },
  "scale": 1,
  "anchor": { "x": 24, "y": 48 },
  "balloon": { "x": 24, "y": 6 },
  "facing": "right",
  "speed": 24,
  "animations": {
    "idle": { "frames": [0, 1], "fps": 2 },
    "walk": { "frames": [{ "index": 2, "ms": 120, "dx": 2 }, { "index": 3, "ms": 120, "dx": 2 }] },
    "surprise": { "frames": [10], "fps": 1, "loop": false }
  },
  "overlays": {
    "blink": { "frames": [12, 13], "fps": 8, "interval": [2500, 6000], "on": ["idle", "walk", "talk"] },
    "mouth": { "frames": [14, 15], "fps": 6, "on": ["talk"] }
  },
  "lines": {
    "greet": ["やっほー！"],
    "site-stored": ["{title} が更新されたよ！"]
  }
}
```

| キー | 必須 | 内容 |
|---|---|---|
| `format` | ○ | `1` |
| `name` | | 表示名（最大 40 文字） |
| `sprite` | ○ | シートのファイル名（`base` からの相対） |
| `frame.width` `frame.height` | ○ | 1 コマの大きさ（整数 8〜128、シート上の px） |
| `scale` | | 表示倍率（整数 1〜4、既定 1）。画面上の大きさは `frame × scale` CSS px |
| `anchor` | | 足元の点。ピクセルの境目の座標（整数、`0 ≤ x ≤ width`・`0 ≤ y ≤ height`。`y = height` はコマの下端、`x = 24` は 23 列目と 24 列目の境目）。既定は `{x: floor(width / 2), y: height}`。この点を地面（タスクバーの上端）に合わせ、ドラッグ中もこの点を基準に動かす |
| `balloon` | | 吹き出しの尾が指す点（ふつうは頭のすぐ上）。座標の取り方は `anchor` と同じ（整数、`0 ≤ x ≤ width`・`0 ≤ y ≤ height`）。既定はコマの上端の中央（`{x: width / 2, y: 0}`）。使い方は下記「[吹き出しの位置](#吹き出しの位置)」 |
| `facing` | | シートの絵が向いている向き（`right` / `left`、既定 `right`）。逆向きは水平反転で描く（反転しても `anchor`・`balloon` が同じ部位に来るよう、`x` を `width - x` に写す）。`flip: false` のアニメーションの間は反転しない |
| `speed` | | 歩く速さ（シート上の px / 秒、0 より大きく 1000 以下、既定 24）。`walk` のコマに `dx` が 1 つも無いときだけ使う |
| `animations` | ○ | 名前 → アニメーション。`idle` は必須 |
| `overlays` | | 重ね絵（`blink`・`mouth`） |
| `lines` | | せりふ |

同梱パックの `balloon` は、`yureko` が `{x: 32, y: 3}`（頭のすぐ上）、`mochi` が `{x: 28, y: 9}`（リボンの左の輪のすぐ上）、`neko` が `{x: 19, y: 8}`（`idle` の頭のすぐ上）。

**アニメーション**: 名前は `idle`（待機）・`walk`（歩く）・`talk`（吹き出しを出している間）・`sleep`（寝る）・`surprise`（おしらせが来たとき）・`drag`（つままれている間）・`fall`（落ちている間）。`idle` 以外は省略でき、無いものは `idle` で代用する。各アニメーションは `{frames, fps?, loop?, flip?}`:

- `frames`: 空でない配列（最大 256 要素）。要素はコマ番号（整数、表示時間は `1000 / fps` ms）か `{index, ms?, dx?, dy?}`。`ms` は表示時間（省略時 `1000 / fps`）。どちらの書き方でも、各コマの表示時間は 16〜60000 ms でなければならない。`dx` はそのコマに入ったときに進む横方向の距離（シート上の px、向いている方向が正、`-frame.width`〜`frame.width`）で、`walk` でだけ使う（`walk` のどれかのコマに `dx` があれば、歩く距離は `speed` ではなく `dx` の合計で決まる）。`dy` はそのコマを描く縦のずれ（シート上の px、下が正、`-frame.height`〜`frame.height`）で、位置は変えない（跳ねる絵などに使う）。吹き出しの点と当たり判定は `dy` ぶん絵と一緒にずれる。
- `fps`: 0 より大きく 60 以下の数、既定 4（表示時間の範囲から、実際に使えるのは 1/60 以上）。
- `loop`: 既定 `true`。`false` なら最後のコマで止まる。
- `flip`: 既定 `true`。`false` なら逆向きのときも水平反転せずシートの向きのまま描く（絵の中の文字が裏返らないようにするため。同梱パックはどちらも `sleep` の「z」に使う）。ふるまいは下記「[ふるまい](#ふるまい)」。

**重ね絵**: 同じシートの同じ大きさのコマを、土台のコマのちょうど上（`dy` も同じ）に重ねる。`frames`・`fps` はアニメーションと同じ書き方（`loop` は無視）。

- `blink`: 今のアニメーションが `on`（既定 `["idle", "walk", "talk"]`）に含まれる間、`interval`（`[最小, 最大]` ms、どちらも 100〜600000 で最小 ≤ 最大、既定 `[2500, 6000]`）のあいだの乱数の間隔で 1 回ずつ再生する。
- `mouth`: 今のアニメーションが `on`（既定 `["talk"]`）に含まれ、かつ吹き出しの文字送りが終わるまでの間、繰り返す。

**せりふ**: 種類 → 文字列か文字列の配列（出すたびに 1 つを無作為に選ぶ。各 200 文字まで）。無い種類は組み込みの日本語の既定文を使う。

| 種類 | 出すとき | 差し込み |
|---|---|---|
| `greet` | Desktop 画面を初めて表示したとき（1 回だけ。「ひとりごとを言う」を外していれば出さない） | |
| `site-stored` | おしらせが 1 件 | `{title}`（`title` をサニタイズして最大 60 文字、無ければ `d`）、`{d}`、`{count}` |
| `sites-stored-many` | おしらせが 2 件以上 | `{count}` |
| `fetch-error` | 更新の確認に失敗したとき | |
| `recovered` | 失敗の後に確認できたとき | |
| `idle` | ときどき（数分に 1 回まで。「ひとりごとを言う」を外していれば出さない） | |
| `click` | マスコットをクリックしたとき | |

**検証**: 知らないキーは無視する（先の版で足すキーの余地）。次のどれかに当たるパックは `console.warn` を出して丸ごと読み飛ばし、ページは壊さない: `format` が `1` でない、`idle` が無い、上の型・範囲に合わない値がある（`anchor`・`balloon`、既知のアニメーション・重ね絵の中身を含む）、`sprite` が `base` の外を指す、マニフェストかシートを読み込めない、シートを読み込んだ後に使っているコマ番号がシートのコマ数を超える、シートの幅・高さ（`naturalWidth`・`naturalHeight`）が上の上限を超える、シートの画素を読み出せない（下記「[当たり判定](#当たり判定)」のマスクを作れない）。

## ふるまい

1 体ごとの状態機械（`desktop-mascot-behavior.js`）で動く。地面は `#desk-screen` の下端（＝タスクバーの上端）で、横位置は絵がスクリーンからはみ出さない範囲に収める。スクリーンの大きさが変わるたびに（`ResizeObserver`）地面と範囲を取り直す。

- **待機 ⇄ 歩く**: 待機が数秒続くたびに、半分ほどの確率で地面の上の無作為な位置へ歩く（「歩きまわる」を外していれば歩かず、歩いている途中なら止まる）。
- **寝る**: 操作もおしらせも無いまま 1〜2 分たつと寝て、しばらくすると起きる。クリック・ドラッグ・吹き出しでも起きる。
- **反転しないアニメーション**: 状態が変わって今のアニメーションが `flip: false` になると、その回のループ（`update`）のうちに向きをシートの `facing` に変え、そのアニメーションの間はその向きのままにする（`walk` を `flip: false` にすると進む向きに関わらずシートの向きで描く）。描画・吹き出しの点・当たり判定はどれもこの向きで決まる。終わった後は元の向きに戻さず、次に歩くときに進む向きへ向き直る。
- **驚く**: おしらせが来ると `surprise` を 1 秒ほど再生する（おしらせを受け持たない他の体も驚く）。
- **話す**: 吹き出しを出している間は歩かず `talk` を再生する。
- **ドラッグ**: 絵の不透明な画素（下記「[当たり判定](#当たり判定)」）を押して 3px 以上動かすとつまみ上げ（`drag`）、離すと重力で地面まで落ちる（`fall`）。ポインタ座標は `toDeskPx` で `#view-desktop` 内の座標に換算する。動かさずに離せばクリック扱い。
- コマ送りと移動は全体で 1 本の `requestAnimationFrame` ループが進め、Desktop 画面が表示されていてタブが前面にある間だけ回す。コマ送り（`desktop-mascot-sprite.js::createPlayer` の `advance`）は、繰り返すアニメーションで前回から 1 周ぶん以上たっていれば周回ぶんをまとめて飛ばし（その間の `dx` は周回数 × 1 周の `dx` の合計として足す）、1 回の呼び出しで進めるコマはコマ数 + 1 までに抑える。

## 当たり判定

マスコットは、コマの枠（`frame × scale` の矩形）の中で、いま描いている絵の不透明な画素だけがポインタを受ける。透明な画素のところを押すと、下にあるもの（デスクトップ・アイコン・リンク集ページのリンクなど）にそのまま届く。吹き出しは枠全体（矩形）で受ける。

- **マスク**: パックのシートを読み込んだ後に 1 回だけ canvas に描いて `getImageData` で画素を読み、アルファ値が 128 以上（0〜255 のうち半分以上不透明）の画素を 1 ビットで持つ（シートの上限 2048 × 2048 ピクセルでも 512 KiB）。シートは同一オリジンなので canvas は汚染されない。
- **当たる画素**: 土台のコマと、いま見えている重ね絵（`blink`・`mouth`）のコマのどれかで、その点の画素が不透明なら当たる。点は `scale` で割ってシートの画素に写し、左右反転中は列を `width - 1 - 列` に写し、各レイヤーの `dy` ぶん上下にずらして引く（`dy` でずれた絵のうち、枠の外にはみ出た部分は当たらない）。`prefers-reduced-motion: reduce` のときは止めて出している `idle` の最初のコマだけで判定する。
- **切り替えの仕組み**: `.desk-mascot` は既定で `pointer-events: none` で、ポインタが不透明な画素の上にあるマスコット 1 体にだけ `is-hot` クラスを付けて `pointer-events: auto`・`cursor: grab` にする。判定はトップの文書とリンク集ページ（iframe）の文書の `pointermove`（タッチ以外）のたびと、ループの各フレーム（ポインタが止まったままでもマスコットが歩いてきたとき）に、最後のポインタ位置でやり直す。iframe の中の座標は `desktop-scale.js::frameToViewport`（iframe 要素の矩形の左上 + 座標 × 矩形の幅 / iframe の `innerWidth`）でトップの文書のビューポート座標に直し、iframe の文書のイベントは `desktop.js` が iframe の読み込みのたびに `DesktopMascots.watchFrame(doc)` で結ぶ。判定するのは枠がその点を含む体だけ。
- **重なり**: `#desk-mascots` の子を後ろ（手前に描かれるもの）から順に見て、最初に当たった体を取る。途中に点を含む開いた吹き出しがあれば、それより奥の体は当たらない。
- **ドラッグ中**: つまんでいる体は、離すまで `is-hot` のまま（ポインタキャプチャで追う）。離したらその位置で判定し直す。
- **ホバーの無い押下（タッチ・ペンなど）**: トップの文書と iframe の文書の `pointerdown` をキャプチャ段階で見て、押した点がマスコットの不透明な画素に当たっていれば、下の要素への `pointerdown` を止めて（`preventDefault`・`stopPropagation`）その体のドラッグ/クリックを始める。トップの文書ではマスコットにポインタキャプチャを移し、iframe の文書ではその文書の `pointermove`/`pointerup`/`pointercancel` を追う。この押下に続く `click` はその文書で 1 回だけ捨てる（離してから 500 ms 経っても来なければ捨てるのをやめる）。タッチなら続く `touchstart` を `preventDefault` してスクロールを止める。モーダルが開いているとき、押した先が `#desk-mascots` の中（`is-hot` のマスコット・吹き出し）か、トップの文書で `#desk-screen` の外のときは何もしない。

## 吹き出し

Win95 のツールチップ風（`#ffffe1`・1px の黒枠・PixelMplus12）で、マスコットを指す小さな尾（高さ 6px）を持つ。文字は 1 字ずつ送る（先に全文ぶんの大きさを取っておくので、送っている間に大きさは変わらない）。マスコットをドラッグすると付いて動く。文字はすべて `textContent` で入れる。

### 吹き出しの位置

- **点**: パックの `balloon`（左右反転中は `x` を `width - x` に写す）に、いま描いている土台のコマの `dy`（`prefers-reduced-motion: reduce` のときは `idle` の最初のコマの `dy`）を足し、`scale` 倍して枠の左上からの位置にしたもの。跳ねる絵でも尾が頭に付いて動く。
- **上に置く**: 吹き出しの下端を点の 6px 上に置き、尾の先を点の 1px 上に合わせる。左右は点を中心にし、スクリーンの内側（端から 4px）に収める。尾は点の真上に置き、吹き出しの左右の端から 4px より外には出さない。
- **下に置く**: 上に置くと吹き出しの上端がスクリーンの上端から 4px 未満になるときは、マスコットの枠の下端の 6px 下に置き（地面より下にはみ出すなら上へ詰める）、尾を上下反転する。尾の左右の位置は上に置くときと同じ（点の真下）。下に置くときの基準は `balloon` ではなく枠の下端。

### おしらせ

- **振り分け**（`desktopUpdates` の `sites-stored`）: 1 回ぶんのおしらせを 1 体に渡す。おしらせの吹き出しを開いている体か、つままれている間のおしらせを預かっている体があればその体に渡して合流させ（おしらせの吹き出しが同時に 2 つ開かないようにするため。既読はその吹き出しの中で最も新しい `stored_at` まで進めるので、2 つあると先に閉じた側がもう一方の分まで既読にしてしまう）、無ければ表示中の体の間で順番に回す。表示をやめた体（狭い幅・コントロール パネルでの選択解除）が持っていたおしらせも、同じ規則で選んだ体に引き継ぐ。つままれている間に来たおしらせは離したときに出す。パックの読み込みが終わる前に来たおしらせは、読み込み後に振り分ける。
- **中身**: 1 件なら `site-stored` のせりふとサイトのタイトルのリンク、2 件以上なら `sites-stored-many` のせりふと新しい順に最大 5 件のタイトルのリンクと「ほか N 件」。リンクは `href`（`gateway_url` か `url`）を `target="_blank" rel="noopener noreferrer"` で開く。`href` が `http://`・`https://` で始まらない項目は（`collectNotices` で除くので通常は来ないが）リンクにせずタイトルを文字だけで出す（判定は `util.js::isHttpUrl`。`maybeLink` と同じ）。「とじる」ボタンで閉じるまで出したまま。
- **既読**: おしらせの吹き出しのリンクを開く（クリック・中クリック）か「とじる」を押すと、その吹き出しに入っているおしらせの `storedAt` の最大値で `desktopUpdates.acknowledge` を呼ぶ（[`desktop.md#更新の確認`](desktop.md#更新の確認)）。それ以外の閉じ方（狭い幅に切り替わって体が隠れたときなど）では既読にしない（隠れた体のおしらせは表示中の体に引き継ぐ）。
- **読み上げ**: おしらせのせりふとタイトルを `aria-live="polite"` の領域（`#desk-mascot-live`）に入れる。

### ひとこととクリック

- **ひとこと**（`greet`・`idle`・`click`・`fetch-error`・`recovered`）: 文字を送り終えてから 4 秒で閉じ、既読には関わらない。吹き出しをクリックしても閉じる。おしらせの吹き出しが開いている体は、ひとことを出さない。
- **クリック**: 出していないおしらせを持っている体はそれを出し、無ければ `click` のせりふを言う。

## マスコットタブ

「コントロール パネル」（[`desktop.md#コントロール-パネル`](desktop.md#コントロール-パネル)）の「マスコット」タブ（`desktop-mascot-settings.js::MascotSettingsPage`）。

- **表示するマスコット**: 読み込めたパック（`/mascots/index.json` の順）をチェックボックスの一覧で出す。各行はパックの表示名（無ければ id）と `idle` の最初のコマの静止画（48×48 の枠に収まる最大の整数倍、枠より大きいコマは等倍のまま上端・左右中央に合わせて枠で切り取る）。行を選ぶ（クリックかチェックボックスへのフォーカス）と、上のモニタの枠の中に同じコマを収まる最大の整数倍で出す。全部外してもよい（マスコットは 1 体も出ず、おしらせも出ない）。パックの読み込みが終わるまでは「よみこみちゅう…」、1 つも無ければ「マスコットがありません」と出す。
- **更新の確認**: コンボボックスで 1 分 / 5 分 / 15 分 / 30 分 / 確認しない（既定 1 分）。[`desktop.md#更新の確認`](desktop.md#更新の確認) の間隔になる。
- **動き**: 「歩きまわる」（外すとその場で待機・話す・寝るだけになる。ドラッグはでき、離せば落ちる）と「ひとりごとを言う」（外すと `greet`・`idle` のせりふを出さない。おしらせ・`click`・`fetch-error`・`recovered` は出す）。どちらも既定でオン。
- **永続化**: `web/storage.js` 経由で `swing:desktop:mascot` キー（`desktop-mascot-settings.js` で定義）に `{"packs": [id, ...], "interval": 60, "walk": true, "chatter": true}` の形の JSON で保存する。`interval` は秒で `60`/`300`/`900`/`1800` か `null`（確認しない）。`packs` が `null` なら読み込めたパックを全部出す。`packs` が無い・壊れた/想定外の値は項目ごとに既定（`["yureko"]`・60 秒・`true`・`true`）へ落とす。
- **`packs` の決まり**: チェックを付け外しすると、保存する `packs` は「今チェックの付いているパックの id」を一覧の順に並べたものになる。全部にチェックが付いていれば `packs` に `null`（全部表示）を書き、1 つでも外れていればその一覧を書く。一覧を保存した後で `mascots_dir` に足したパックは、チェックを付けるまで出ない。一覧にあって今は読み込めないパックの id（`mascots_dir` から消したものなど）は無視し、次にチェックを付け外しして保存したときに一覧から落ちる。
- **適用**: 保存値はページ読み込み時に 1 回 `localStorage` から読んでメモリに持ち、OK/適用のたびに再読み込みせずその場で当てる（`DesktopMascots.applySettings` がマスコットを足し引きし、外したマスコットが持っていたおしらせは表示中の先頭の体に引き継ぐ。間隔は `desktopUpdates.setInterval`）。保存に失敗したらエラーを出し、保存値は変えない。

## 層・フォーカス・幅

- マスコットと吹き出しは `#desk-screen` の中の `#desk-mascots`（`z-index: 10`）に入る。アイコンと SWING Explorer ウィンドウより上、コントロール パネルのオーバーレイ・ダイアログより下。足元はタスクバーの上端に乗る。
- `#desk-mascots` 自体はポインタを受けず、吹き出しと、不透明な画素の上にポインタがあるマスコットだけが受ける（上記「[当たり判定](#当たり判定)」）。マスコットはフォーカスを受けず（`aria-hidden`）、吹き出しのリンクと「とじる」は Desktop 画面の Tab の巡回に入る（`#view-desktop` の実機能コントロールにリンクも数える）。フォーカスのある吹き出しが閉じたら「SWING Explorer」アイコンへ移す。
- 表示するマスコットは、選んだ順に、表示の幅（フレームの幅 × `scale`）の合計が `#desk-mascots` の幅の 1/4 に収まるところまで出す（先頭の 1 体は必ず出す）。幅が変わるたびに決め直す。

## 動きを減らす設定

`prefers-reduced-motion: reduce` のときは歩かず落ちず、`idle` の最初のコマを止めて出し、重ね絵も出さない（当たり判定と吹き出しの点もこのコマで決める）。吹き出しは出すが文字送りはしない。ドラッグはでき、離すとその場で地面に戻る。
