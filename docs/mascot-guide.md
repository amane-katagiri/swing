# マスコットのパックを作る

Desktop 画面を歩き回るマスコットを自分で作る人向けの手引き。キーの意味・値の範囲・検証規則の正本は [`architecture/dashboard/mascot.md#パック形式-1`](architecture/dashboard/mascot.md#パック形式-1) と [`architecture/dashboard.md#マスコットのパック配信srcdashboardmascotsrs`](architecture/dashboard.md#マスコットのパック配信srcdashboardmascotsrs)。この文書と食い違うときはそちらに従う。

## パックの置き方

```
<mascots_dir>/
  my-cat/            ← ディレクトリ名がパックの id（英小文字・数字・ハイフン、32 文字まで）
    manifest.json
    sprite.png       ← PNG・GIF・WebP のどれか 1 枚
```

`mascots_dir` は設定の `[dashboard] mascots_dir`（環境変数 `SWING_DASHBOARD_MASCOTS_DIR`）で指定し、`swing up` を再起動すると読み込まれる。パックを足したり直したりしたときも再起動が要る。表示するかどうかは Desktop 画面の「コントロール パネル」の「マスコット」タブで選ぶ。

## 最小のパック

`idle` だけあれば動く。歩くときも `idle` の絵のまま横に動くので、実際には `walk` もあったほうがよい。

```json
{
  "format": 1,
  "name": "わたしのねこ",
  "sprite": "sprite.png",
  "frame": { "width": 32, "height": 32 },
  "animations": {
    "idle": { "frames": [0, 1], "fps": 2 },
    "walk": { "frames": [2, 3, 4, 5], "fps": 8 }
  }
}
```

## 用意するコマ

| アニメーション | コマ数の目安 | 使う場面 | 無いとき |
|---|---|---|---|
| `idle` | 1〜2 | 待機。2 コマで上下に 1px 揺らすと、止まっていても生きて見える | 必須 |
| `walk` | 4〜6 | 歩く | `idle` のまま滑る |
| `talk` | 1〜2 | 吹き出しを出している間 | `idle` |
| `sleep` | 2 | しばらく放っておいたとき | `idle` |
| `surprise` | 1〜2 | おしらせが来たとき（`"loop": false` で 1 回だけ） | `idle` |
| `drag` | 1〜2 | つままれて宙づりの間 | `idle` |
| `fall` | 1 | 離されて落ちる間（`drag` と同じコマでもよい） | `idle` |

重ね絵（任意）:

| 重ね絵 | コマ数 | 内容 |
|---|---|---|
| `blink` | 1〜2 | 目を閉じた絵。目のところだけを描き、ほかは透明にする |
| `mouth` | 2 | 口の開け閉め。吹き出しの文字送りに合わせて動く |

同梱の `mochi`（`web/mascots/mochi/`）はこの表をすべて使っている例、`neko` は重ね絵なしの例、`yureko` は重ね絵に `mouth` だけを使う例になっている。

## シートの描き方

- **コマの並べ方**: 同じ大きさのコマを格子状に並べる。番号は左上から右へ 0, 1, 2…、行の端まで行ったら次の行へ続く。
- **大きさ**: 1 コマ 32〜64px くらいが扱いやすい。大きく見せたいときは描き込みを増やすより、`scale` を 2 か 3 にするほうがドット絵らしさが残る。
- **右向きで描く**: 既定の `facing` は `right` で、左向きは自動で左右反転して描く。左向きで描いたなら `"facing": "left"` にする。
- **足元の線をそろえる**: 全部のコマで、足のいちばん下の行を同じ高さにする。`anchor`（足元の点、既定はコマの下端の中央）をその下端に合わせると、地面（タスクバーの上端）にぴったり立つ。そろっていないと、アニメーションが切り替わった瞬間に沈んだり浮いたりする。
- **頭と体を動かさない**: 歩くコマで体の位置がコマごとに左右にぶれると、カクカクして見える。揺らすなら、全体を上下に 1px までにする。
- **透明は透明に**: アルファ値が 128 未満の画素はクリックが下に抜ける。輪郭をぼかす（アンチエイリアスする）と縁の当たり判定が欠けるので、くっきり描く。
- **重ね絵の位置**: `blink`・`mouth` のコマは、土台のコマとぴったり重なる位置に描く。

## 歩き方の合わせ方

歩く速さの決め方は 2 通りある。

- **`dx` で決める**: `walk` の各コマに `{ "index": 2, "ms": 80, "dx": 2 }` のように、そのコマで進む距離を書く。地面に着いている足が次のコマで後ろへずれた分と `dx` を同じにすると、足が滑らない。足をはっきり動かす絵（同梱の `neko`）に向く。
- **`speed` で決める**: `walk` のどのコマにも `dx` を書かなければ、`speed`（シート上の px / 秒、既定 24）でなめらかに進む。足が小さくしか動かない絵（同梱の `mochi`）に向く。

どちらも `scale` 倍されて画面上の速さになる。

## 吹き出しと向き

- **吹き出しの位置**: 吹き出しの尾は、`balloon` で指定した点（既定はコマの上端の中央）を指す。頭の上に透明な余白があるときは、`"balloon": { "x": 16, "y": 6 }` のように頭のすぐ上を指定すると、吹き出しが浮かない。
- **反転させたくないアニメーション**: 寝ているときの「z」のように文字や左右非対称の飾りを描いたアニメーションには、`"flip": false` を付ける。マスコットはそのアニメーションに入るときにシートの向きへ振り向くので、文字が裏返らない。

## せりふ

`lines` に、種類ごとに文字列か文字列の配列を書く（配列なら出すたびに 1 つを選ぶ）。書かなかった種類は組み込みの文を使う。

```json
"lines": {
  "greet": ["にゃー"],
  "site-stored": ["{title} が更新されたみたい"],
  "sites-stored-many": ["更新が {count} 件あるよ"],
  "site-published": ["{title} を公開したよ"],
  "replica-added": ["{title} をミラーしてくれる人が増えたよ"],
  "click": ["なあに？"]
}
```

種類と差し込める値（`{title}`・`{d}`・`{count}`）の一覧は [`architecture/dashboard/mascot.md#パック形式-1`](architecture/dashboard/mascot.md#パック形式-1) の「せりふ」の表を参照。

- おしらせのせりふは 3 組ある。ミラーしているサイトの保存（`site-stored`・`sites-stored-many`）、自分のサイトの公開（`site-published`・`sites-published-many`）、自分のサイトをミラーしてくれる人が増えたとき（`replica-added`・`replicas-added-many`）。それぞれ 1 件用と 2 件以上用がある。
- 種類の違うおしらせが同時に来ると、種類ごとのせりふを 1 行ずつ並べて 1 つの吹き出しに出す。1 つのせりふは 1 行で読める長さ（全角 20 字ほどまで）にしておくと、並べたときに吹き出しが縦に伸びすぎない。
- 1 件用のせりふには `{title}` を入れておくと、何のおしらせかが分かりやすい。2 件以上用は `{count}` を使う（`replicas-added-many` の `{count}` はサイトの数）。

## 確かめ方

1. `mascots_dir` に置いて `swing up` を再起動する。
2. パックが読み込まれないときは、まず `swing up` のログを見る（サーバ側で落としたパックは、理由付きの警告が出る）。
3. ログに何も出ていなければ、ブラウザの開発者ツールのコンソールを見る。マニフェストの値の範囲などはブラウザ側で確かめていて、合わないパックは理由付きの警告を出して読み飛ばす。
4. 「コントロール パネル」の「マスコット」タブに名前とプレビューが出れば読み込めている。

よく引っかかる制限:

- `manifest.json` は 64 KiB まで、シートは 1 MiB まで。シートの幅・高さは 4096px まで、幅 × 高さは 2048 × 2048 ピクセルまで。
- シートの拡張子と中身の形式が一致していること（PNG を `.gif` という名前で置くと読み込まれない）。
- シンボリックリンクとハードリンクは使えない。
- コマの表示時間は 16〜60000ms（`fps` なら 60 まで）、1 つのアニメーションは 256 コマまで。
- パックは 32 個まで（id の順に先頭から）。

## 配布するときは

パックは画像とテキストだけで、スクリプトは動かない。人に配るときは、絵の権利（自分で描いたものか、使ってよいもの）とライセンスを添える。
