# SWING Explorer のロゴを S+E モノグラムにする

## 決めたこと

- Desktop ビューの「SWING Explorer」のアイコンを、S と E を組み合わせた独自のモノグラムに差し替えた。対象はデスクトップのショートカット（`icon-desk-swing`、30px、白一色）とタイトルバー・タスクボタン（`icon-desk-swing-color`、16px、色付き）。Start ボタンは SWING Explorer ではなく OS 側の記号なので、SWING 本体の 3 色マーク（`icon-desk-start`）のまま残した（タイトルバー・タスクボタンと共用していたシンボルを 2 つに分けた）。サイドナビのロゴ（`.swing-logo` / `.swing-logotype`）とリンク集ページのバナー画像は別のマークなので触っていない。
- 構図は左上に S・右下に E。S の下のボウルが E の左上の肩に掛かり、E 側に隙間が開く。「引っかかっている」ことは、S を上に描き、E から S の線 +3.5 ぶんを抜いた隙間で表す。
- S と E の両方が交差する本物の鎖状の組み方（互いに上下が入れ替わる）も試したが、E の縦棒と横棒が接する角でしか交差できず、E が食われて読めなくなる。16px での可読性を優先して、S が手前・E が奥の 1 方向に決めた。
- 図形は線（stroke）のまま持ち、`<defs>` に `swing-se-s` / `swing-se-e` として 1 組だけ置いて 2 つの `<symbol>` から `<use>` する。色違いのファイルは作らない（ロゴタイプと同じ方針）。
- S は上下 2 つの円弧（中心 (16.8,14) 半径 8 と 中心 (22.8,30) 半径 10）を接線でつないだ幾何学的な形。線幅は 7。細いと 16px で潰れ、太いとボウルの中が埋まるので、カウンターが 16px 換算で 2px 強残る太さに取った。
- `viewBox` は図形の外接矩形に合わせて `5 2 54 60` に詰めた。`0 0 64 64` のままだと 16px / 30px のときにマークが一回り小さくなる。
- 白版は `stroke="currentColor"` にして `.desk-icon-glyph-solid` から `color` で色を渡す。選択時に水色（`#a8c8ff`）へ変える既存の規則をそのまま使うため。
- 色版は S が金、E が青のグラデーション。青の暗い側は最初 `#2050c8` にしたが、紺のタイトルバーの上で沈むので `#3a86f0` まで明るくした。

## 検証

- `web/` をローカルで静的配信し、Chrome の headless で Desktop ビューを撮って、デスクトップアイコン（30px・白）、タイトルバー・タスクボタン（16px・色付き）を実寸で確認した。`docker/demo/demo.sh up`（`web/` は `include_str!` で焼き込まれるので mirror の作り直しが要る）でもデモ環境の Desktop 画面を確認した。
