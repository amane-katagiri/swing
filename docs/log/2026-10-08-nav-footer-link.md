# ナビのフッタに yureko.samoyed.moe へのリンクを足す

ダッシュボードのサイドナビのフッタ（ミラーセット名とバージョン）の下に、<https://yureko.samoyed.moe/> への「ゆれ子のSWING日記」のリンクを足した。

## 決めたこと

- リンクは設定で変えるものではないので、`index.html` に固定で書く。新しいタブで開き、`rel="noopener noreferrer"` を付ける。
- ログイン画面には出さない。最初は隠しておき、ログイン後に `/api/overview` を読んでフッタを埋めるときに出し、ログインが切れてログイン画面に移ったら隠す。
- 文言は日記の名前なので、表示言語によらず同じにする。
- 760px 以下でナビのフッタの代わりに出すページ最下部のフッタにも同じリンクを出す。ミラーセット名とバージョンは `#page-footer-text` に入れ、リンクはその下の行に置く。

## 検証したこと

- `cargo test --workspace` が通る。
- デモ環境で、幅 1280px のサイドナビのフッタではバージョンの下に、幅 390px のページ最下部のフッタではミラーセット名とバージョンの下に、リンクが中央揃えで出ること、ログイン画面には出ないことを確かめた。
