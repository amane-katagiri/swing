# サイドナビの折りたたみとアイコン

## 決めたこと

- サイドナビを下端のトグルで畳めるようにし、状態を `localStorage["swing:nav:collapsed"]` に保存する。CSP でインラインスクリプトを使えないので、状態の反映は `app.js` の初期化で行う（テーマと同じ扱い）。
- 畳んだときに見せるアイコンは外部アイコンセットを使わず自前の SVG `<symbol>` にした（ライセンス表記を持ち込まないため）。Sites は星、Webring はブランドロゴの輪を太くしたもの、Publish はロケット、Settings は歯車。
- ウェイト合わせ: アイコンは 20px・stroke 1.75（現在の画面だけ 2 でアクセント色）、ラベルは通常 500・現在の画面 600。歯車は歯を詰めると重く見えるので外径 9.6・8 枚にとどめ、ロケットは幅を広げて星・歯車と同じくらいの面積にした。ブランドロゴも輪 3・ノード 3.75（viewBox 48）に太らせてラベルと釣り合わせた。
- 現在の画面の強調は `body[data-view=…] a[data-route=…]` の列挙をやめ、`aria-current="page"` で当てる。
- `<use>` で参照した SVG の中身にはページの CSS セレクタが届かないので、Webring のノードの塗りは `<symbol>` 側の属性（`fill="currentColor"`）で指定する。

## 検証

- 静的配信した `web/` をブラウザで開き、展開・折りたたみ・再読み込み後の復元、ダークテーマ、760px 以下の横並び表示を目視確認。
- モバイル幅では shell が縦並びになり `flex-basis` が高さとして効くので、畳んだ状態の `flex-basis` を `auto` に戻す必要があった。

## デモ環境（`docker/demo/`）

- 確認用に上げたデモが最初は実 relay と公開 IPFS につながっていたので、外に出ない構成を `docker/demo/` にまとめた。ipfs・relay・mirror を `internal: true` のネットワークに閉じ込め、ホストへの入口は socat の中継コンテナだけにする。コード側の見落としに依らずネットワークで遮断するため。
- 外部と通信する経路を洗い出した: 設定済み relay（nostr-sdk 0.45 は gossip 既定無効）、NIP-05 の HTTPS 取得、Kubo swarm。NIP-05 は必要なときだけ `SWING_DEMO_NIP05=1` で mirror を外部ネットワークにもつなぐ。
- 検証: 隔離時は mirror・ipfs・relay のいずれからも `1.1.1.1:443` に届かず、NIP-05 モードでは mirror だけ届くことを確認。ダッシュボード（18082）と Gateway（18080）はどちらのモードでも応答する。

## 折りたたみの調整

- アニメーション中、幅は滑らかに縮むのにラベルの非表示と padding の切り替えが一瞬で起きていたため、中身だけ先に畳まれてアイコンが横に跳ねていた。nav の左右 padding を両状態で共通（8px）にし、アイコン・ロゴの左余白を畳んだ幅の中央に来る値（11px）に固定した。ラベル類は視覚的に隠すのをやめ、不透明度のフェードと `overflow: hidden` による切り取りにした。
- トグルは枠付きで右寄せ。右余白を固定しているので、畳んだ幅ではちょうど中央に来て、アニメーション中は nav の右端と一緒に動く。
- 読み込み時の縮むアニメーションは、module（defer 扱い）の `app.js` で状態を反映していたのが原因。CSP でインラインスクリプトは使えないので、`<body>` 直後に同期実行する `/boot.js` を追加して最初の描画前に `data-nav` を付けるようにした。最初の rAF から幅が 64px のままであることを確認。

## デモのサンプルデータ

- `docker/demo/seed.sh` を追加した。架空の参加者の鍵で既存の CLI（`publish`・`mirror add`）を実行するだけにして、専用のシード用コードは持たない。プロトコルどおりのイベントが実装自身の経路で作られるため。
- webring は自分から深さ 5 まで伸びるように組んだ（相互 5 組、片方向 8 本、Follow Set の無い末端 1 人、サイトの無い参加者 1 人、複数サイト・複数版の参加者を含む）。
- CLI の `mirror add` は agent に通知しないので、シード後に mirror を再起動して Follow Set をすぐ読ませる。relay の DB は volume にして、mirror を作り直してもデータが残るようにした。

## 読み込み時の英語のちらつき

- 静的な訳も module の `app.js` が当てるので、日本語表示でも最初の描画は `index.html` の英語になっていた。辞書を通常スクリプトに移すと `i18n.js` と二重管理になるため、`boot.js` で言語だけ判定し、英語以外なら訳が当たるまで `[data-i18n]` を隠す方式にした。`app.js` が失敗したときに文字が消えたままにならないよう、1 秒後に CSS アニメーションで表示に戻す。
- 日本語設定で、最初の rAF では英語ラベルが hidden、訳が当たった後に visible になることを確認。英語設定では最初から visible。
