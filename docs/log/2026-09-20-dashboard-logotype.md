# ダッシュボードのロゴタイプ差し替え

## 決めたこと

- サイドナビのブランド名のテキスト（`.swing-brand-name`、system-ui の "SWING"）を、渡されたサンプル SVG（`swing-logotype-gradient-lines-balanced.svg`、560×162）のロゴタイプに置き換えた。
- ロゴと同じ扱いで、色違いのファイルは作らずインライン SVG にして CSS で色を付ける。横縞の文字は `--swing-text`、2 つの丸は `--swing-accent`。`data-theme` の手動切り替えと `custom.css` のアクセント上書きにそのまま追従する。
- 元 SVG の `viewBox` は図形の外接矩形にほぼ一致していた（丸まで含めて x 0〜560, y 0〜161.82）ので、そのまま使う。
- 高さは最初 17px（元のブランド名のキャップハイトに合わせた大きさ）にしたが、縞が 1px 強になり潰れて読めなかった。ロゴと同じ 26px にして、`.swing-logotype-body` にだけ `shape-rendering: crispEdges` を付けた。丸はアンチエイリアスを残したいので本体だけに限定している。
- テキストではなくなるので `role="img"` と `aria-label="SWING"` でアクセシブルな名前を付けた。
- ナビを畳んだときの不透明度 0 とモバイル幅の扱いは、元のブランド名と同じ規則をそのまま引き継いだ（`.swing-brand` の `overflow: hidden` で切り取られる）。

## 検証

- ローカルで `web/` を静的配信し、ライト・ダーク・モバイル幅（400px）のブランド行を確認した。アクセントの丸がライトでリンクブルー、ダークでライムに追従している。
