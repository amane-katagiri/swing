# 自分の情報に絵文字のフィンガープリントを出す

Publish 画面の「自分の情報」には npub と hex しかなく、Sites 画面や Webring 画面で自分のアカウントを見分けるときの絵文字と見比べられなかった。

## 決めたこと

- `GET /api/overview` に自分の pubkey の `fingerprint` を足した。ほかの DTO と同じくサーバ側で求める（平文の http では `crypto.subtle` が使えないため）。セットアップモードでは `pubkey`・`npub` と同じく `null`。
- 自分の情報の hex の次に「フィンガープリント」の行を足し、ほかの画面と同じ `fingerprintBadge` で 4 つ出す。
- 絵文字は画像なので、選んでもコピーできない。行にコピーボタンを置いて、異体字セレクタを付けた絵文字の文字を区切り無しでつないだものをコピーする。チャットなどに貼って相手と見比べやすいように、空白は入れない。

## 検証

- `cargo fmt`・`cargo clippy`・`cargo test` が通った。
- デモ環境で Publish 画面を幅 1100px と 375px で表示し、hex とミラーセットの間に 4 つの絵文字が並ぶことを確かめた。
