# README のロゴロックアップ

## 決めたこと

- ダッシュボードのブランド行と同じロゴ（`.swing-logo`）とロゴタイプ（`.swing-logotype`）を横に並べた SVG を作り、README の先頭に貼った。置き場所は `docs/assets/`。
- 図形はダッシュボードの `web/index.html` のインライン SVG をそのまま使う。ロゴは `viewBox="95 42 392 392"`、ロゴタイプは `viewBox="0 0 560 162"` を `transform` で 120px 高に揃え、間隔はナビのブランド行の比率（ロゴ高 26px に対しギャップ 12px）に合わせて 55 にした。キャンバスは 590×120。
- ダッシュボードは CSS 変数で色を付けているが、README では変数が使えないので色を焼き込んだ 2 ファイルにした。ライトは本体 `#000000`・丸 `#0645ad`、ダークは本体 `#ffffff`・丸 `#7dff3c`（`--swing-text` と `--swing-accent` のライト／ダークの値）。
- テーマの切り替えは SVG 内の `prefers-color-scheme` ではなく `<picture>` + `media` 属性でやる。SVG 内のメディアクエリは img 埋め込みだと OS の設定に従うため、GitHub のテーマ設定と食い違って白地に白抜きになりうる。
- 縞が細いので `shape-rendering="crispEdges"` はダッシュボードと同じく本体にだけ付け、丸はアンチエイリアスを残した。

## 検証

- ライト（白地）とダーク（`#0a0a0a` 地）で 590px 幅にラスタライズして、縞の潰れがないこと・丸の色がテーマに追従していることを目視確認した。
