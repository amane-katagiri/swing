# favicon を Start ボタンのマークにする

- Desktop 画面の Start ボタンに使っている SWING の 3 色マーク（`icon-desk-start`）を、ダッシュボードの favicon にした。2026-09-19 のロゴ作業で「favicon は別途用意する」としていた分。
- `index.html` のインライン `<symbol>` は外から参照できないので、同じ図形を単独の SVG として `web/favicon.svg` に置き、`/favicon.svg`（`image/svg+xml`）で配信する。`index.html` の `<head>` に `<link rel="icon" href="/favicon.svg" type="image/svg+xml">` を足した。
- SVG 非対応ブラウザ向けに `web/favicon-32.png`（32×32、透過）と、iOS のホーム画面向けに `web/apple-touch-icon.png`（180×180、白背景で周りに余白。iOS は透過部分を黒で埋めるため）も用意した。どちらも ImageMagick 7 で `favicon.svg` を高解像度（`-density 1200`）でラスタライズしてから縮小して書き出した。ICO は用意していない。
- `<head>` では PNG の `icon` に `sizes="32x32"` を付けて SVG より前に置く。Chromium は候補が複数あると後ろのものや大きさ指定のないものを選ぶので、この並びなら SVG 対応ブラウザは SVG を選ぶ。
- 書き出し: `magick -background none -density 1200 web/favicon.svg -resize 32x32 -strip PNG32:web/favicon-32.png`、`magick -background none -density 1200 web/favicon.svg -resize 148x148 -background white -gravity center -extent 180x180 -strip PNG24:web/apple-touch-icon.png`。
- 検証: `cargo fmt` / `cargo clippy --all-targets -- -D warnings` / `cargo test`、デモ環境で `/favicon.svg` が `image/svg+xml` で返り、`/` の `<head>` に link が入っていることを確認。PNG 2 つも `image/png` で返ることを確認。SVG を 128px に描いて見た目がスタートボタンのマークと同じことを確認。
