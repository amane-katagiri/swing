# README の Desktop 画面の素材に Windows 風のカーソルを映す

README の Desktop 画面のアニメーションと静止画に、Windows 9x 風のマウスカーソルを映すようにして撮り直した。

## 決めたこと

- 録画ツールが重ねるカーソルは Windows 風にならないので使わず、撮影するブラウザだけに入れる初期化スクリプトがページの最前面に要素を置いてカーソルを描く。アプリのコードには手を入れない。
- 絵は Windows の画像を使わず、似た形のドット絵を文字の格子で書いてスクリプトの中で canvas に起こす。矢印・リンクの手・開いた手・握った手・上下と左右と斜めのリサイズを用意し、左右は上下の転置、右上がりの斜めは左上がりの左右反転で作る。
- 形は、カーソルの位置にある要素の CSS の `cursor` で決める。iframe は同一オリジンなので中の文書まで辿る。マスコットは `grab` なので、押している間は押した時点の形を保ち、`grab` なら握った手にする（アプリは `grabbing` を指定していない）。
- SWING Explorer の中のページ（iframe）のポインタイベントは親に届かないので、iframe 側の初期化スクリプトが座標を親の座標に直して渡す。
- カーソルが飛んで見えないよう、スクリプトの移動をすべて時間をかけたものにした。マスコットは動いているので、近づいてから位置を取り直して短く寄せる。コントロール パネルのアイコンはセレクタ指定のダブルクリックの前にカーソルを運ぶ。
- 移動に時間をかけた分、録画は約 16 秒・2.4MB になった。

## 検証

デモ環境で撮り、コマを並べて、矢印が全体に映り、マスコットの上で開いた手・つまんでいる間は握った手になり、ダイアログをドラッグしている間は矢印のままであることを確かめた。静止画もダイアログの上に矢印が映り、マーキーの文字と点灯した NEW バッジが写っていることを見て確かめた。
