# 追加修正の見直し

[レビューの残りの対応](2026-10-07-review-followups.md) とそれに続く修正を、前の経緯を知らない別のレビューで評価し直し、指摘を直した。これを 5 回繰り返し、最後の評価で CRITICAL・HIGH・MEDIUM の指摘がなくなったので終えた。公開の時計の確認の経緯は [`2026-10-07-publish-clock-guards.md`](2026-10-07-publish-clock-guards.md) に書いた。

## 決めたこと

- `[gateway].hosts` とダッシュボードの待ち受け IP を比べるのは、両方が IP のときだけにする。待ち受けが `0.0.0.0`・`::` のときに比べる値が両方とも「無し」になって一致し、名前のゲートウェイのホストをすべて断っていた。Docker Compose の構成では起動できなくなる不具合だった。判定は `host::is_listen_ip` にまとめ、ダッシュボードの Host の検証と同じものを使う。
- グループやほかのユーザーから書き込めるディレクトリは、持ち主が root でも、どの階層でも断る（`install.sh` と `swing service install --system`）。親にグループの書き込みを許すと、そのグループのメンバーは子のディレクトリごと差し替えられるので、root の持ち物の親だけを例外にしても守れるものがない。Debian の `root:staff 2775` の `/usr/local` には入れられなくなるので、`--prefix /opt/swing` を案内する。
- そうしたディレクトリの下では、アンインストールも断る。一度は「消すだけなら安全」として続けたが、親に書き込める人が `lib/swing` を別の root の持ち物のインストールへのシンボリックリンクにすり替えると、そちらのファイルを消させられた。手で消すためのコマンドを表示する案も、表示したパスを実行までにすり替えられるのでやめた。持ち主しか書き込めないようにしてから再実行するよう案内するだけにする。
- アンインストールは、確かめた `lib/swing` に `cd -P` で一度だけ入り、そこから相対パスで `./swing` の実行と削除を行う。検査の後でパスがすり替えられても、実行と削除の先は動かない。
- 自分の報告の読み込みに失敗したり最後まで読めなかったりしたら、次の定期の報告ラウンドで 1 回だけ読み直す。サイトを保存した後の同期では読み直さない。時刻で間隔を決めると、ラウンドの開始時刻のずれで `poll_interval` の 2 倍に延びることがあった。

## 変えたもの

- ダッシュボードのロックは `state.locks` からだけ取る。公開のロックは、持っていることを型で示す `PublishLock` を残す。
- Windows のプロセス・ジョブ・スナップショットのハンドルを `OwnedHandle` で持つ。
- ダッシュボードのセキュリティの文書に、Host を上流の IP に書き換えるリバースプロキシの扱いと、LAN の IP で待ち受けたときにも Kubo のゲートウェイの既知の弱点が当てはまることを書いた。

## 検証したこと

- `cargo fmt`・`cargo clippy -D warnings`・`cargo test --workspace`・Windows 向けの `cargo xwin clippy` が通る。
- 本物の Kubo で `#[ignore]` の統合テスト（`kubo_integration`・`mfs_kubo_integration`・`kubo::` のプロセス管理）が通る。
- `packaging/linux/test-install.sh` が、一般ユーザーと root（Debian のコンテナ）で通る。root のときは、すり替えたシンボリックリンクや別のユーザーの持ち物の `lib/swing` からアンインストールしても何も消さないことも確かめる。
- デモ環境（`docker/demo/demo.sh up --seed`）で、サンプルの保存とレプリカ報告が動くこと、ダッシュボードから続けて公開すると別の `created_at` の版になることを確かめた。

## 残したもの

- 別のユーザーの持ち物だと断るときのメッセージには、解決した実体のパスをそのまま出す。信頼したシンボリックリンクの先が書き込める場所だと、改行や制御文字を含む名前が root の端末に出うる（表示だけで、何も実行しない）。
- 同じ秒の公開の衝突を防ぐ `created_at` の選び方はプロセスの中でだけ効き、CLI とダッシュボードの公開は互いに排他しない。
- 読み込めていない間のラウンドでは報告が同じ秒に並ぶので、1 ページを超えると、後の読み込みで一部を取りこぼしうる（`report_ttl` で失効する）。
