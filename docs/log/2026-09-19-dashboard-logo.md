# ダッシュボードのロゴ差し替え

## 決めたこと

- 渡されたサンプル SVG（`logo2.svg`、512×512）を、サイドナビのロゴ（4 点付きの輪）と置き換える。
- 色違いのファイルは用意せず、インライン SVG に CSS 変数で色を付ける。`data-theme` の手動切り替えや `custom.css` のアクセント上書きにそのまま追従させるため。
- 2 トーンにする。軌道は `--swing-text`、中央と両端の丸は `--swing-accent`。
- 元の SVG は余白が大きく 26px では小さすぎるので、`translate` を外して図形の外接矩形（x 96〜486、y 74〜402）を求め、長辺 390 に 1 ずつ余白を足した正方形 `viewBox="95 42 392 392"` を中心合わせで切り出した。
- favicon は別途用意するので今回は扱わない。

## 検証

- デモ環境で、ライト・ダーク・ナビを畳んだ状態のロゴ表示を確認した。
