# 通常の投稿にハッシュタグを付ける

`--note`（ダッシュボードのチェックボックスも同じ）で出す kind 1 の投稿に、ハッシュタグ `swingpublish` を付けた。

## 決めたこと

- 本文の末尾に `#swingpublish` を足し、NIP-24 の `t` タグ（`swingpublish`）も付ける。Nostr クライアントのハッシュタグ検索やタイムラインは本文ではなく `t` タグを relay に問い合わせる（`#t` フィルタ）ので、タグが無いと本文に書いても見つからない。本文にも書くのは、クライアントがハッシュタグとしてリンク表示できるようにするため。
- タグは固定にし、利用者が選べるようにはしていない。
- 綴りは `swingpublish` にした。`t` タグの値としては `_` も使えるが、本文中の `#swing_publish` をどこまでハッシュタグと見なすかはクライアントの実装によって違い、`_` で切れたり強調の記法と見なされたりするおそれがあるので避けた。NIP-24 に従い小文字にした。
- サイトイベント（kind 35980）には付けていない。

## 検証

- `nostr::site_note_content` と `nostr::build_site_note_builder` の単体テストで、本文の末尾と `t` タグを確かめた。
