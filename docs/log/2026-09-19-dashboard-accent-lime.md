# ダッシュボードのアクセントをダークは黄緑、ライトは青に変更

## 決めたこと

- ダークモードはサイバーレトロ風の明るい黄緑にする。`--swing-dark-accent: #7dff3c`（背景 `#0a0a0a` とのコントラスト比 15.3）、hover 用の `-strong` はさらに明るい `#b1ff8a`、`-soft` は `rgb(125 255 60 / 14%)`。
- ライトモードは白背景だと黄緑のままでは読めない（コントラスト比 1.3 前後）。同じ色相で明度を落とした濃い緑も試したが、ライトはリンク色らしい濃い青のほうがよいとのことで、色相を揃えるのはやめた。`--swing-accent: #0645ad`（白背景比 8.5）、`-strong: #08318f`、`-soft: rgb(6 69 173 / 12%)`。
- `.swing-btn-accent` と選択中のスイッチは文字色が `var(--swing-bg)` なので、ダークは黄緑に黒文字、ライトは青に白文字になり、どちらも読める。専用の `--swing-on-accent` は足していない。
- 緑系だった `--swing-ok` がダークのアクセントと見分けにくくなるので、両テーマともティールに寄せた（ライト `#2f7a6e`、ダーク `#6fc9b8`、`-soft` も同じ色で透過）。
- ダークは最初は色相 82° の `#b8ff3c` で入れたが、もう少し緑寄りにしたいとのことで、明度と彩度はそのままに色相を 100° へ寄せた。ライトの濃い緑（82° の `#4a7a00`、100° の `#297a00`）もこの段階で試した。

## 検証

- デモ環境で、Sites と Webring の画面をライト・ダーク両方で表示して確認した。
