# Desktop のリンク集ページの星空

## 決めたこと・作ったこと

- リンク集ページ（`web/desktop-page.css`）の `html` の背景の星を、`radial-gradient(1px 1px at X% Y%, …)` 8 個から、`shape-rendering='crispEdges'` の SVG タイル 2 枚の敷き詰めに置き換えた。
  - 160×160 のタイルに 1px と 2×2 の点（白・薄い青・薄い黄）。
  - 232×208 のタイルに 5px と 7px の十字（7px の十字は中央 3px を白くする）。
  - タイルの寸法をずらして、繰り返しを目立たせない。
- 理由: 旧実装は星が 8 個しかなく、位置が `html` の幅に対する % なので大半が中央のカラムの裏に隠れ、左右の帯には 1〜数個の薄い点しか残らずドット抜けのように見えた。1px の放射グラデーションは小数 px の位置でにじむので、整数 px の `<rect>` で描いた。
- README の `docs/assets/dashboard-desktop.webp` と `.png` を [`docs/assets/capture.md`](../assets/capture.md) の手順で撮り直した。

## 確かめたこと

- デモ環境で 1440×900 と 1280×800 の Desktop 画面を表示し、左右の帯に星と十字がにじまずに出ることを拡大して確かめた。
- 撮り直した WebP のコマを並べ、マスコットを持ち上げたコマがあること、マスコットがダイアログに被らないこと、ダイアログが最後に所定の位置で止まることを確かめた。静止画はマーキーの文字が全部見え、NEW バッジが点灯している。
- `cargo test --workspace dashboard` が通る。
