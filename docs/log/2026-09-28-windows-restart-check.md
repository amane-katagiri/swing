# Windows の再起動後の確認（タスクトレイ）

[Windows 実機での確認](2026-09-26-windows-hands-on-check.md)で残した「サインインし直したときに、トレイが出て『動作中』になること」を、[設定ファイルの相対パスを設定ファイルのディレクトリから解決する](2026-09-27-config-relative-paths.md)変更（`c220ad7`）を含むビルドで確かめた。コードは変えていない。

## 確かめたこと

- `service install` した日本語の表示言語の Windows を再起動してサインインすると、`swing-tray` がトレイに出て「動作中」になった。
- 設定ファイルの相対パスの `state_dir` が、プロセスのカレントディレクトリではなく設定ファイルのディレクトリから解決されるようになったことが、この構成で効いていた。

## 残したこと

- 英語の表示言語で、トレイの文言が英語になることと、`schtasks` による登録判定が正しく働くこと（`docs/todo.md` に残したまま）
