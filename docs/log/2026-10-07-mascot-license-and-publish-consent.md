# 同梱マスコット「ゆれ子」のライセンスと、publish の配布の許諾を明記する

## 決めたこと

- 同梱のマスコットのうち「ゆれ子」（`web/mascots/yureko/` のキャラクターとその画像）を MIT License の対象から外し、権利を留保する。キャラクターを別の作品やグッズなどに使われないようにするため。`mochi`・`neko` はこれまでどおり MIT License で配る。
- ただし留保だけにすると、フォーク・パッケージ・コンテナイメージなどで SWING を配り直す人がゆれ子のファイルを配れなくなり、MIT で配っている本体と食い違う。そこで「SWING とその改変版・再配布物の一部としてなら、改変せずに複製・配布・表示できる」という許諾を添える。CC BY-ND 4.0 も考えたが、改変しなければ SWING と関係のない用途にも使えてしまうので、独自の文にした。
- `swing publish` について、publish することで参加者が各版を保存・複製し、IPFS やゲートウェイで配布・表示することを許したものとして扱う、と `docs/guide/publish.md` に書く。これまでは publish という行為からの黙示の許諾に頼っていて、どこまで許したのかが文書になかった。自分が権利を持たないものを含めるときの注意も添える。

## 変えたもの

- `README.md` と `docs/release/README.md` のライセンスの節に、ゆれ子の例外と許諾の範囲を書いた。
- `docs/guide/publish.md` の冒頭に、publish したサイトが参加者に保存・配布されることと、その許諾の扱いを書いた。

## 残したもの

- `Cargo.toml` と Homebrew の formula（`packaging/homebrew/swing.rb.in`）の `license` は `MIT` のまま。ゆれ子はバイナリに埋め込まれるが、どちらもパッケージ全体のライセンスを 1 つの識別子で示す欄で、例外は README に書いたため。
