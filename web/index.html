        Key

        SWING talks to the signer app over a relay. Every few days it requests a signature on its own for the replica report (kind 35981) of each stored site. While the signer app is offline, SWING cannot publish, change the mirror list, or refresh replica reports.

        Signer apps you can use Any signer app that supports NIP-46 connections started from a nostrconnect:// link works. For example: Android: Amber (not on Google Play; install it from Zapstore, Obtainium, or its GitHub releases) iPhone / iPad: Clave (on the App Store; it wakes up by push notification to sign even while closed)

        When the signer app asks for approval, choosing to always allow requests from SWING is recommended. To confirm publishing and mirror-list changes every time instead, allow only kind 35981 for SWING in the signer app’s per-app permissions, if it has them.
